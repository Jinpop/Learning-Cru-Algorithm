# Learning-Cru-Algorithm

이 강의는 **기초 자료구조/알고리즘을 이미 알고 있고, 문제도 어느 정도 풀어본 경험이 있지만**

막상 **난이도 있는 문제(중상~상)** 나 **실전 코테 환경(시간 압박/변수 많은 조건)** 에서 흔들리는 분들을 위한 **실전 강화형 강의**입니다.

---

## 강의에서 배우는 것

- 문제를 빠르게 정리하는 방법(조건/목표/제약을 기반으로 방향 잡기)
- 유형을 판별하는 기준과 체크포인트(정렬, 이분탐색, DP, 그래프 등으로 연결)
- 떠오른 아이디어를 **풀이 형태로 만들기**(핵심 관찰 → 설계 → 간단한 검증)
- 실전에서 자주 하는 접근 실수 줄이기(과한 가정, 놓치는 조건, 복잡도 착각)

## 이런 분에게 추천해요

- 기본 알고리즘은 알지만 **중상 난이도에서 접근이 막히는 분**
- 문제를 보면 **알고리즘부터 떠올리는** 분
- 풀이를 보기 전까지는 방향을 못 잡는 느낌이 있는 분
- “생각은 났는데 확신이 없다”가 자주 반복되는 분

## 목표

문제를 보면 **접근 방향을 빠르게 잡고**, 그 방향을 스스로 검증할 수 있는 **재현 가능한 문제풀이 루틴**을 갖추는 것.
