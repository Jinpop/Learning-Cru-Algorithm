# 강의 소개

이 강의는 **기초 자료구조/알고리즘을 이미 알고 있고, 문제도 어느 정도 풀어본 경험이 있지만,**

막상 **난이도 있는 문제(중~상)** 나 **실전 코테 환경**에서 흔들리는 분들을 위한 **실전 강화형 강의**입니다.

강의는 C++로 진행될 예정이지만 편한 프로그래밍 언어를 사용하시면 됩니다.

---

## 강의에서 배우는 것

- 문제를 빠르게 정리하는 방법(조건/목표/제약을 기반으로 방향 잡기)
- 유형을 판별하는 기준과 체크포인트(정렬, 이분탐색, DP, 그래프 등으로 연결)
- 떠오른 아이디어를 **풀이 형태로 만들기**(핵심 관찰 → 설계 → 간단한 검증)
- 접근이 떠오르지 않을 때 택할 수 있는 전략
- 실전에서 자주 하는 접근 실수 줄이기(과한 가정, 놓치는 조건, 복잡도 착각)

## 강의 진행 방식

강의용 문제를 준비해서 직접 풀이하며 접근 방법에 대해 익숙해지게 강의를 진행할 예정입니다.

1. 문제의 조건을 분석하고,
2. 접근법을 고민하고,
3. 접근한 로직의 시간복잡도를 계산 및 검증하고,
4. 구현까지 보여줄 예정입니다.

강의에서 풀이한 문제는 과제로 나갈 예정이고,

해당 과제 코드는 다음주차의 강의시간에 리뷰를 해드릴 예정입니다.

## 강의 커리큘럼

1주차: 오티 (1시간)

환경 설정, 코테, 시간 복잡도 개념 설명 등

2주차: 문제 분석 하기 (2시간)

문제의 구성을 이해하고, 조건을 빠르게 분석하고, 맞는 접근법을 찾는 것

3주차: 실전 문제 풀이 (2시간)

특정 문제가 주어 졌을 때 (조건 분석 → 접근 → 풀이 → 검증 → 구현)의 단계를 직접 해보며 익숙해지는 것

4주차: 모의 코테 (1시간)

배운 것을 토대로 모의 코테를 진행하고 해설까지 진행

## 이런 분에게 추천해요

- “백준 골드 문제는 장벽”으로 느껴지는 분.
- 기본 알고리즘은 알지만 **응용 문제에서 접근이 막히는 분**
- 문제를 보면 **알고리즘부터 떠올리는** 분
- 풀이를 보기 전까지는 방향을 못 잡는 느낌이 있는 분
- “생각은 났는데 확신이 없다”가 자주 반복되는 분

## 목표

문제를 보면 **접근 방향을 빠르게 잡고**, 그 방향을 스스로 검증할 수 있는 **재현 가능한 문제풀이 루틴**을 갖추는 것.
